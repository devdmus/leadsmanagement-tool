# 🚀 Fix Dashboard API Error - Setup Guide\n\n## The Problem\nYour dashboard is showing **\"Error Loading Dashboard\"** because the API URL is wrong.\n\n### Current (Wrong):\n`\n/wp-api/leads?api_key=SECRET123\n`\n\n### Should Be:\n`\nhttp://yoursite.com/wp-json/crm/v1/leads?api_key=SECRET123\n`\n\n---\n\n## Quick Setup (3 Steps)\n\n### Step 1: Add WordPress Site\n\n1. In the CRM app, click **\"Sites\"** in the left menu\n2. Click **\"Add Site\"** button\n3. Fill in:\n - **Site Name:** `My WordPress Site` (or any name)\n - **Site URL:** `http://localhost` or `http://yoursite.com` (your actual WordPress domain)\n - **Username:** (optional - for WordPress basic auth)\n - **App Password:** (optional - for WordPress app passwords)\n4. Click **Save**\n\n**⚠️ Important:** The URL must be where WordPress is actually installed!\n\n**Examples:**\n- ✅ `http://localhost/wordpress` - WordPress in /wordpress folder\n- ✅ `http://localhost` - WordPress in root\n- ✅ `https://example.com` - Your actual site\n- ❌ `http://localhost:8080/wp-admin` - Don't include `/wp-admin`\n- ❌ `/wp-api` - Not a full URL\n\n### Step 2: Verify WordPress Plugin is Active\n\n1. Go to WordPress admin: `http://yoursite.com/wp-admin`\n2. Click **Plugins**\n3. Search for **\"Activity Logs API\"**\n4. Should show **\"Active\"** status\n5. If not active, click **Activate**\n\n### Step 3: Reload Dashboard\n\n1. Go back to CRM app\n2. Navigate to **Dashboard**\n3. **Refresh the page** (F5)\n4. Open **DevTools** (F12) → Console\n5. Look for:\n - ✅ Green `[wpLeadsApi] Fetched X leads` = Success!\n - ❌ Red error = Check below\n\n---\n\n## Troubleshooting\n\n### Issue 1: Still Getting \"API_BASE is empty\"\n**Cause:** No site configured in Sites menu\n**Fix:** Complete Step 1 above\n\n### Issue 2: \"HTTP 500\" Error\n**Cause:** WordPress not found or plugin issue\n**Fix:**\n1. Verify WordPress URL is correct\n2. Check WordPress plugin is installed and activated\n3. Check API key matches WordPress setting\n\n### Issue 3: \"HTTP 404\" Error\n**Cause:** Wrong endpoint or WordPress not set up\n**Fix:**\n1. Test the URL directly in browser:\n - Go to: `http://yoursite.com/wp-json/crm/v1/leads?api_key=SECRET123`\n - Should return JSON data, not an error\n2. If 404, plugin endpoints not registered\n3. Activate the plugin again or check WordPress installation\n\n### Issue 4: \"Unexpected token '<', '<!DOCTYPE'\"\n**Cause:** Getting HTML error page instead of JSON\n**Fix:**\n1. Check Site URL is correct\n2. Verify WordPress plugin is active\n3. Test endpoint with curl:\n `bash\n   curl \"http://yoursite.com/wp-json/crm/v1/leads?api_key=SECRET123\"\n   `\n Should return JSON, not HTML\n\n---\n\n## Verify Backend Server is Running\n\nThe app also needs the backend server running on port 3001:\n\n`bash\ncd server\nnpm run dev\n`\n\nShould show:\n`\nServer running on http://localhost:3001\n`\n\n---\n\n## Complete Setup Checklist\n\n- [ ] Backend server running on port 3001 (`npm run dev` in `/server` folder)\n- [ ] Frontend running on port 5173 (`npm run dev` in root folder)\n- [ ] WordPress site URL in `.env` or Sites menu\n- [ ] WordPress plugin \"Activity Logs API\" is **active**\n- [ ] API key in `.env` matches WordPress plugin setting\n- [ ] Browser console shows green ✅ logs, not red ❌ errors\n- [ ] Dashboard displays stats instead of 0\n\n---\n\n## Where is Your WordPress?\n\nBefore proceeding, you need to know:\n1. **Is WordPress installed locally** on your machine?\n - If yes: What's the URL? (e.g., `http://localhost/wordpress`)\n - If no: Do you want to set up local WordPress?\n\n2. **Is WordPress installed on a remote server?**\n - If yes: What's the domain? (e.g., `https://example.com`)\n\nOnce you know this, you can configure the site correctly.\n\n---\n\n## Need Help?\n\n1. Check the console log messages (F12 → Console)\n2. Look for the 🔍 \"Fetching from:\" message to see what URL it's using\n3. Test that URL directly in browser\n4. If it returns JSON, the setup is correct\n5. If it returns HTML or error, WordPress is not properly set up\n
