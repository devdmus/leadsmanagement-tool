# ✅ Dashboard Error - STEP-BY-STEP FIX\n\n## 🔴 Your Error\n`\nError Loading Dashboard\nUnexpected token '<', \"<!DOCTYPE\" ... is not valid JSON\nFetching from: /wp-api/leads\n`\n\n**What this means:** The app is trying to fetch leads from a wrong URL (`/wp-api`) and getting an HTML error page instead.\n\n---\n\n## ✅ The Fix (Choose One)\n\n### Option A: You Have Local WordPress\n\n**If you have WordPress installed locally:**\n\n1. **Open the CRM app** in your browser\n2. **Click the \"Sites\" menu** (left sidebar)\n3. **Click \"Add Site\"** button\n4. **Fill in:**\n - Name: `My Local WordPress`\n - URL: `http://localhost` OR `http://localhost/wordpress` (depending on your setup)\n5. **Click Save**\n6. **Go back to Dashboard**\n7. **Press F5 to refresh**\n8. **If still error, open F12 Console and check the new error message**\n\n---\n\n### Option B: You Have WordPress on a Web Server\n\n**If you have WordPress on yoursite.com:**\n\n1. **Open the CRM app**\n2. **Click \"Sites\" menu**\n3. **Click \"Add Site\"**\n4. **Fill in:**\n - Name: `My Live Site`\n - URL: `https://yoursite.com` (your actual domain)\n5. **Click Save**\n6. **Go back to Dashboard**\n7. **Refresh page**\n\n---\n\n### Option C: You Don't Have WordPress Yet\n\n**If you need to set up WordPress:**\n\n1. Install WordPress locally (using XAMPP, Docker, etc.) or rent hosting\n2. Once installed, get the URL where it's accessible\n3. Follow Option A or B above\n\n---\n\n## 🔍 Verify the Fix Works\n\n### After configuring a site:\n\n1. **Open DevTools** (F12)\n2. **Go to Console tab**\n3. **Refresh the page** (F5)\n4. **Look for success messages:**\n\n ✅ **Success** (you should see):\n `\n   🔍 [wpLeadsApi] Fetching from: http://yoursite.com/wp-json/crm/v1\n   ✅ [wpLeadsApi] Fetched X leads from http://yoursite.com/wp-json/crm/v1\n   ✅ [DashboardPage] Stats loaded successfully\n   `\n\n ❌ **Still Error** (check what you're getting):\n - If HTTP 500: WordPress site issue or plugin may not be active\n - If HTTP 404: Plugin endpoints not found - activate the \"Activity Logs API\" plugin\n - If HTML error: WordPress not found at that URL\n\n---\n\n## 🛠️ If You're Still Getting Errors\n\n### Error: \"API_BASE is empty\"\n→ You didn't add a site or it didn't save. Try adding the site again.\n\n### Error: \"Got HTML error page instead of JSON\"\n→ WordPress is not at the URL you provided. Check:\n 1. The URL is spelled correctly\n 2. WordPress is installed there\n 3. The site is running (for local: server is running)\n\n### Error: \"HTTP 404\"\n→ The WordPress plugin endpoints are not found: 1. Go to WordPress admin\n 2. Click Plugins\n 3. Find \"Activity Logs API\"\n 4. If **Inactive**: Click **Activate**\n 5. If **Not installed**: Install it first\n\n### Error: \"HTTP 500\"\n→ WordPress server error. Check:\n 1. WordPress can load at the URL\n 2. Database is working\n 3. Check WordPress error logs\n\n---\n\n## 📋 Complete Checklist\n\nBefore you finish troubleshooting:\n\n- [ ] At least one WordPress site is added in \"Sites\" menu\n- [ ] Site URL is correct (can access it in browser)\n- [ ] WordPress plugin \"Activity Logs API\" is **Active** in WordPress\n- [ ] Backend server is running (port 3001)\n- [ ] Frontend app is running (port 5173)\n- [ ] Browser console shows green ✅ messages, not red ❌ errors\n- [ ] Dashboard page loads stats instead of 0\n- [ ] No \"Error Loading Dashboard\" toast\n\n---\n\n## 💡 Pro Tips\n\n### Test the endpoint directly:\n\nIn your browser address bar, try:\n`\nhttp://yoursite.com/wp-json/crm/v1/leads?api_key=SECRET123\n`\n\nIf it returns JSON data, the WordPress API is working!\nIf it returns 404 or error page, the plugin is not activated.\n\n### Check if backend server is running:\n\nIn another terminal (in the `server` folder):\n`bash\nnpm run dev\n`\n\nYou should see:\n`\nServer running on http://localhost:3001\n`\n\n### Enable debug mode:\n\nPaste this in browser console to see detailed debug info:\n`javascript\nconst sites = JSON.parse(localStorage.getItem('crm_wp_sites') || '[]');\nconsole.log('Saved sites:', sites);\nif (sites.length > 0) {\n  console.log('First site URL:', sites[0].url);\n  console.log('WordPress API endpoint would be:', sites[0].url + '/wp-json/crm/v1');\n}\n`\n\n---\n\n## 🆘 Still Need Help?\n\nProvide these details:\n1.
